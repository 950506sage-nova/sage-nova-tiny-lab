# Nova 的手机 · 互动原型

一个纯前端、单文件的手机界面模拟项目。无需安装依赖，打开 `index.html` 即可运行，也可以通过 GitHub Pages 发布。

## 当前功能

- 四位数字锁屏（演示密码：`2026`）
- 手机桌面与应用入口
- 微信式聊天窗口，可发送消息并保存在当前浏览器
- 相册、笔记、浏览器、购物、生活、游戏、邮箱和设置等模拟应用
- 应用内标签切换与内容详情弹窗
- 笔记和聊天记录通过浏览器 `localStorage` 保存
- 手机屏幕自适应布局

## 运行

直接在浏览器打开 `index.html`。也可以在仓库设置中启用 GitHub Pages，并将发布目录设为 `/(root)` 或项目目录对应的发布源。

## 说明

这是一个前端交互原型，不会连接真实微信、支付、购物或邮件服务。聊天、笔记等数据只保存在当前浏览器本地；清除浏览器站点数据后会丢失。演示密码仅用于体验，不是安全认证。

## 后续可以扩展

- 自定义锁屏密码和主题
- 增加应用内页面、图片相册和可编辑卡片
- 导入/导出本地数据
