# Project Note — 2026-10-19

## Observation

The page keeps the visit counter in a JavaScript variable and displays submitted text only in the current page. Refreshing the page resets both, because neither value is saved.

## Suggested improvement

Use browser localStorage to save and restore the counter and latest message. This keeps the first version server-free and browser-local. Cross-device sync would need a backend and a separate privacy review.

## Check

Increment the counter, submit a short message, refresh, and confirm both values remain. Clear local storage and confirm the page returns to its default state.
